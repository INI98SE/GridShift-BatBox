# GridShift: BatBox (ESP32-C3 Physical Minecraft IC2 Energy System)

Фізична реалізація та інтелектуальна симуляція енергохранилища **BatBox** із легендарного мода **IndustrialCraft 2 (Minecraft)**.

Проект воссоздає логіку ігрової енергомережі IC2 в реальному світі. Він конвертує фізичні Ватти потужності (виміряні високоточним датчиком **INA219**) у віртуальні ігрові **еЕ/т (EU/t)**, синхронізуючи розрахунки з ігровими серверними тіками (1 секунда = 20 тіків).

## ⚡ Особливості та механіки (Features)
* **Синхронізація з ігровим рушієм:** Обсвіт ігрових тактів відбувається кожні 50 мс (рівно 1 тік Майнкрафта).
* **Інтелектуальне згладжування (EMA фільтр):** Алгоритм фільтрує фізичні шуми датчика струму, завдяки чому на екрані відображаються чіткі фіксовані значення споживання (наприклад, рівно `2.00 EU/t` для Дробарки або `16.00 EU/t` для Індукційної печі).
* **Захист від високої напруги (МФЕ ліміт):** Якщо вхідна потужність кабелю перевищує безпечний пакет у **32 еЕ/т**, BatBox моментально йде в захист, блокує лінії живлення та виводить аварійне попередження про необхідність понижуючого трансформатора.
* **Ультракомпактне залізо:** Вся логіка працює на крихітному мікроконтролері ESP32-C3 Super Mini.

## 🛠️ Використовувані компоненти (Hardware)
* **Мікроконтролер:** ESP32-C3 Super Mini (RISC-V, WiFi/BLE)
* **Датчик живлення:** INA219 (I2C)
* **Дисплей:** OLED 0.96" 128x64 (I2C)
* **Акумулятор:** Li-Ion 18650 EVE (2850 мАг, 3.6V)
* **Живлення та заряд:** Модуль MH-CD42 (5V/2A) / TP4056 + MT3608
